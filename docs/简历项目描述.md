# 简历推荐版本

**Jetson Nano + STM32 金属垫片视觉分拣系统**  
技术栈：Jetson Nano、TensorRT、OpenCV、STM32F103C6T6、FreeRTOS、UART、TB6600

- 面向中低速五金产线构建“边缘视觉 + 实时分拣”系统：Jetson Nano 部署 FP16 TensorRT 模型识别金属垫片缺口/变形并输出置信度，STM32 完成光电触发、传送带节拍控制与气缸剔除，双机经串口协作形成“感知—决策—执行”闭环；相机断线自动重开、缺陷帧后台 JPEG 落盘供追溯。
- 将 MCU 软件拆分为检测、通信、执行 3 个 FreeRTOS 静态任务，按执行 > 通信 > 检测设置优先级并通过二值信号量同步；设计含版本号、事务序号、结果码和 XOR 校验的双向 UART 协议，引入 ACK、限时重发、重复请求结果缓存及超时失效安全剔除，保证单工件事务幂等。
- 针对 10 KB SRAM 约束将任务、信号量及内核任务改为静态分配并关闭动态 Heap，加入独立看门狗、任务存活监控与双向心跳失联快速剔除，固件 SRAM 占用由 9,504 B 降至 8,128 B（约 14.5%）；定位 PWM 初始化位于调度器启动后及 `Compare > ARR` 导致无脉冲的问题，改为调度前启动并按 ARR 自动配置 50% 占空比；实测触发至决策端到端时延控制在 195 ms 内，满足中低速产线分拣需求。

## 更短版本

- 基于 Jetson Nano（TensorRT FP16）与 STM32F103C6T6 搭建金属垫片缺口/变形检测产线，联动光电传感器、传送带和气缸完成自动剔除闭环。
- 设计 3 任务 FreeRTOS 控制架构及带 `SEQ + XOR + ACK + 超时重发` 的双向 UART 协议，叠加 IWDG 看门狗/任务存活监控与双向心跳（视觉失联 3 s 快速剔除），实现重复帧幂等和通信异常失效安全；将 SRAM 占用降低约 14.5%，解决 PWM 无输出问题，触发至决策时延 ≤195 ms。

> 使用前核实：只有当 195 ms 来自逻辑分析仪或日志的真实统计时才保留“实测”；建议面试时说明统计样本量与 P95/P99。当前仓库没有模型测试集，简历不应添加准确率、漏检率或产能数据。

# 三段式扩展版（项目描述 / 我的工作 / 成果）

【项目经历】
■ 金属垫片缺陷检测与分拣系统 | 2026.01-2026.04 | 个人实践·独立开发

**项目描述**：面向中低速五金产线，基于 Jetson Nano 边缘视觉计算与 STM32 实时控制，实现金属垫片缺口、变形检测及不良品自动剔除的端到端分拣闭环。

**我的工作**：
- 针对 STM32F103C6T6 仅 10 KB SRAM 的资源约束与产线节拍要求，采用 USB 相机、TB6600 等通用模块替代专用控制硬件以兼顾性能与整机成本；将控制软件划分为检测、通信、执行 3 个 FreeRTOS 任务（优先级执行 > 通信 > 检测），通过 3 个二值信号量完成“传感器触发—通信事务—执行完成”同步
- 将任务、信号量及内核 Idle/Timer 任务全部改为静态分配并关闭动态堆，配套栈溢出 Hook、IWDG 看门狗与任务存活监控、双向心跳（视觉失联 3 s 即失效安全快速剔除）与错误停机保护，避免未检工件静默放行
- 设计固定 8 字节、含 SEQ/XOR/ACK 及超时重发的双向 UART 协议：序号匹配 + 结果缓存保证重复帧事务幂等，通信超时、校验失败或视觉异常统一按异常件失效安全剔除；UART 由 9,600 提升至 115,200 bit/s（单帧线速约 0.69 ms）
- Jetson Nano 部署 TensorRT FP16 推理服务并启动预热，独立相机线程持续清空 UVC 缓冲、仅留最新帧（超 200 ms 旧帧不参与判定），读帧失败自动重开相机免重启；缺陷/异常帧经后台线程 JPEG 落盘（时间戳+事务序号命名）供追溯；提供 systemd 单元实现开机自启与进程异常拉起
- 定位并解决 SRAM 链接溢出、PWM 无输出（调度器启动后的死代码、Compare > ARR）及通信超时三类关键问题
- 搭建 GitHub Actions 流水线：固件交叉编译 + Flash/SRAM 预算门禁（超限即失败）+ 协议单元测试，为资源预算与协议行为提供回归保护

**成果**：
- 固件 SRAM 占用 9,504 → 8,128 B（−14.5%），空闲余量 736 → 2,112 B（约 2.9 倍）；生产构建 Flash 占用 56.15%
- 实测光电触发至分拣决策时延 ≤195 ms（不含 120 ms 气缸动作时间），满足中低速产线分拣需求
- 协议单元测试 4/4 通过（拆包/粘包、噪声重同步、坏校验、幂等缓存）

技术栈: C/STM32F103C6T6/FreeRTOS/UART/TB6600/步进电机/Jetson Nano/TensorRT/OpenCV

# 紧凑版 V6（明确双机分工：Jetson 视觉 / STM32 控制）

【项目经历】
■ 金属垫片缺陷检测与分拣系统 | 2026.01-2026.04 | 独立开发
- 面向中低速五金产线构建“边缘视觉 + 实时分拣”系统：Jetson Nano 运行 TensorRT FP16 模型，负责垫片缺口/变形识别与置信度输出；STM32F103 负责光电触发、传送带节拍控制与气缸剔除，双机经串口协作形成“触发—判定—剔除”闭环
- STM32 侧将固件划分为检测、通信、执行 3 个 FreeRTOS 任务，以 3 个信号量完成同步；针对仅 10 KB 的 SRAM 采用全静态分配并关闭动态堆，内存占用由 9,504 B 降至 8,128 B（-14.5%）；新增 IWDG 看门狗与任务存活监控、双向心跳，视觉失联 3 s 即失效安全快速剔除
- 设计带序号、XOR 校验、ACK 确认与超时重发的串口协议：Jetson 按序号缓存判定结果、重发时直接回放避免重复推理；通信超时或校验失败按异常件剔除，保证未检件不流入下一工序
- 定位解决 SRAM 溢出、PWM 无输出等问题；Jetson 侧推理启动预热、相机线程仅保留最新帧并支持断线自动重开，缺陷帧后台 JPEG 落盘追溯；实测光电触发至分拣决策不超过 195 ms，协议单元测试 4/4 通过、CI 预算门禁守护资源占用

技术栈: C/STM32F103C6T6/FreeRTOS/UART/TB6600/Jetson Nano/TensorRT/OpenCV
